# BhoomiSetu – AI-Powered Land Document Assistant

A modern, responsive, and standalone single-file web application for exploring, organizing, and analyzing Indian land records.

## Features
- **Document Analyzer:** Upload PDF, JPG, and PNG documents to extract sample fields (Owner, Khasra, Area, Village, District) and identify inconsistencies with severity tags.
- **Land Record Explorer:** Searchable database with state, district, village, and khasra filters.
- **Document Comparison:** Side-by-side comparison matrix with field diff highlighting.
- **AI Land Assistant:** Domain assistant with knowledge on Jamabandi, Khasra numbers, Mutation (intkal), and Fards.
- **Document Vault & Reports:** Client-side local storage persistence with report generation and text export.
- **Soft Neutral Luxury Palette:** Responsive design with light and dark theme support.

## Usage
Open `index.html` in any modern web browser or deploy directly to GitHub Pages.
